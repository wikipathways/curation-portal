Most of the waiting is the repository's own automation, which runs on GitHub and not in the portal. Rough times, measured on the sandbox repository:

StepTypical timeWhat is happening
Checks on your file a second or two The portal grades the file as soon as you choose it.
Pull request opened, diagram drawn a few seconds The review page exists and shows the portal's drawing straight away.
Repository processing about 9–10 minutes (about 4 once a pending fix to its workflow is in) It reads identifiers and references, draws its own diagram and builds the draft page. Until it finishes, the draft-page link is missing and approval is refused.
Review by a curator depends on people Curators are volunteers; a change request adds a round trip.
Publish workflow about 1 minute Starts when the accepted label is applied. It assigns the WPID, publishes the files and closes the pull request.
Site rebuild 2–4 minutes {{ site_host or 'The site' }} rebuilds with the new pathway page.
Caches catch up up to 10 minutes Until then some visitors may still see the old page, or none.

A first-time contributor's first pull request can wait longer: GitHub holds the repository's automation on it until a maintainer allows it to run, which from the outside looks like nothing happening.

The publication tracker

Once a submission is approved its card shows four stages, and the rest of the review (checks, diagram, checklist) folds away under Review details:

Accepted
A curator approved it and the portal applied the accepted label.
Publish workflow
The repository's publish workflow is queued or running. If it fails, the stage says so with a link to the run.
Published
The workflow reported back with the pathway's WPID and closed the pull request.
Site live
The pathway's page on {{ site_host or 'the site' }} answers with the new version. This is the last step to turn green, a few minutes after Published.

The card refreshes itself while a stage is in progress. If the repository has not reported back about ten minutes after approval, the portal marks the review Not published so a person looks at it. A publication that arrives later still settles it.
