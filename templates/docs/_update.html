To change a pathway that is already on WikiPathways, use the Update existing tab on the Submit page.

  1. Type the pathway's WPID, for example WP554. When you leave the field the portal looks it up and shows its title.
  2. Download the current version with the link that appears, and make your edit on that copy in PathVisio. This matters: an update replaces the whole file, so an edit made on an older copy would quietly undo whatever changed since, and the portal refuses to approve it (see the pathway changed after you started).
  3. Choose your edited file. The same checks as for a new pathway run at once, plus one more: whether the file says it is the pathway you typed. An update is judged on what it changes, so problems the pathway already had are reported as such and do not count against your edit.
  4. Tick what you changed and add a few words if it helps. This becomes the summary a curator reads first. Other needs a sentence of explanation.
  5. Press Submit update.

One editor at a time

GPML files cannot be merged line by line the way text can, so while one update of a pathway is open nobody else can start another. If someone else is editing the pathway, the portal says who; wait until their update is finished. If you upload again while your own update is still open, the new file goes onto the same pull request instead of opening a second one.

While an update is approved and being published it cannot be changed. Wait for it to finish, then start a new update from the published version.
