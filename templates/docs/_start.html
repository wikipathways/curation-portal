WikiPathways keeps every pathway as a GPML file in a GitHub repository. This portal lets you add or change one without using git: you upload the file in your browser, and the portal files it in the right place and opens a pull request for you, a proposed change that curators review before it becomes part of WikiPathways.

What you need

  • A GitHub account. You sign in with it, and your submission is made under your name. When you sign in for the first time GitHub asks you to allow access to your public repositories. It offers no smaller option; the portal uses it only to submit the pathways you upload.
  • A pathway saved as GPML, normally from PathVisio. Files in the current WikiPathways format (GPML 2013a) are accepted.

Try it with an example

Two small example files show what a complete pathway looks like. The second is a revision of the first: it adds the AHR repressor, two interactions, a reference and a cell-type tag, so it is also handy for seeing how an update is compared with what came before.

  • example-pathway.gpml, aryl hydrocarbon receptor activation by dioxin
  • example-pathway-revision.gpml, the same pathway, revised

Choosing one in the submit form shows the checks without sending anything to GitHub. The only remark you should see is about the missing Author, which the examples leave out on purpose: the portal fills in your name. Please do not submit an example: it would open a real pull request on {{ repo }}.

The short version

  1. Sign in and choose your file on the Submit page. The portal checks it straight away and tells you what, if anything, is worth fixing.
  2. Submit. A pull request opens{% if submit_identity != 'bot' %} in your name{% endif %} and appears under My submissions.
  3. A curator reviews the drawn pathway and works through a checklist. They may ask you for changes, which you answer by uploading a corrected file.
  4. {% if pipeline_mode %}When a curator approves, the repository gives the pathway its WPID (its WikiPathways identifier) and publishes it.{% else %}When a curator approves, the pull request is merged and the pathway is part of WikiPathways.{% endif %}
