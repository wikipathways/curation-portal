GPML
The file format of a WikiPathways pathway: an XML file holding the nodes, lines, labels, annotations and references. PathVisio reads and writes it.
PathVisio
The desktop program most pathways are drawn in.
WPID
A pathway's WikiPathways identifier, such as WP554. {% if pipeline_mode %}A new pathway gets one when it is published.{% endif %}
Data node
A box in the pathway that stands for something: a gene, protein, RNA, metabolite, complex or another pathway.
Identifier (annotation)
The database entry a data node refers to, for example Ensembl:ENSG00000106546 or ChEBI:CHEBI:28119. It is what makes the node findable and usable in analyses.
Interaction
A line between two things in the pathway, with an arrowhead saying what kind of relation it is (conversion, stimulation, inhibition, binding and so on).
Anchor
A point on an interaction that another line can attach to, for example a catalyst acting on a conversion.
Group, complex
Several data nodes kept together. A complex is a group whose members bind each other.
ZOrder
The stacking order of the elements in a drawing: which is drawn on top of which.
Repository
The GitHub project that holds every pathway file, here {{ repo }}.
Pull request
A proposed change to the repository, open for review. The portal opens one for every submission.
{% if submit_identity == 'fork' %}
Fork
Your own copy of the repository on GitHub. The portal uses it to hold your submission until it is reviewed.
{% endif %}
Branch
A named line of changes inside a repository. Each submission gets its own.
Curator
A person allowed to approve, reject or ask for changes.
Review
The portal's record of one pull request: its state, checklist, checks and history.
Checklist
The questions a curator answers before approving (the items).
{% if pipeline_mode %}
Draft page
The pathway's page as it will look once published, built by the repository while it processes the pull request.
Workflow, publish workflow
The repository's automation on GitHub. One workflow processes every pull request; the publish workflow runs when a curator approves.
Label
A tag on a pull request. Two of them, accepted and rejected, start the repository's workflows.
{% endif %}
Adopted pull request
One opened on GitHub, for example by the PathVisio plugin, that a curator brought into the portal.
Check-out
The hold an open update has on a pathway, so that two edits of the same file never collide.
CC0
The public-domain dedication all WikiPathways content is released under.
